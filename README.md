## ✨ 핵심 기능

1. **매일 아침 글쓰고 싶게 만드는 리추얼 시스템**
   - **아침 몰입 타이머 & 자체 합성 집중 사운드**: 15/30/45/60분 딥워크 타이머와 Web Audio API로 실시간 생성되는 브라운 노이즈 / 40Hz 감마파 바이노럴 포커스 / 새벽 빗소리 제공
   - **연속 달성 스트릭(🔥) & 28일 잔디 히트맵**: 매일 아침 목표 어절 달성률과 최근 4주간의 글쓰기 일관성을 시각화
   - **오늘의 글감 질문 룰렛 (`🎲 오늘의 글감 질문 뽑기`)**: 아침에 빈 화면 앞에서 막막할 때 내 3대 관심사 축(Content Map)에서 질문을 즉시 제시

2. **Dan Koe의 4대 글쓰기 프레임워크 내장**
   - **🧩 APAG 설득 프레임워크**: `Attention(고통 묘사)` → `Perspective(통념 파괴)` → `Advantage(비전 제시)` → `Gamify(1-2-3 실행 단계)` 가이드 블록 제공
   - **🧱 3단 레고 에세이**: `Problem` → `Insight` → `Solution` 구조화 장문 작성
   - **⚡ 단문 드릴 (Short-Form Drills)**: 통념 반박형, 과거 vs 현재 대비형, 관찰+리스트+결론형 단문 훈련
   - **🌊 자유 사유 (Freeflow)**: 판단 없이 머릿속 안개를 걷어내는 의식의 흐름 모드
   - **💡 Idea Museum (아이디어 묘지)**: 평소에 수집한 문장/훅을 저장해두고 아침 글쓰기 본문이나 SNS 카드로 즉시 삽입

3. **완벽한 개인 프라이버시 ("나만 읽을 수 있는 공간")**
   - **100% 로컬 저장**: 모든 데이터는 외부 클라우드로 전송되지 않으며 로컬 SQLite(`data/vault.db`)와 마크다운 파일(`data/markdown/*.md`)로 이중 백업됩니다.
   - **🔒 나만 읽는 일기 vs 🌐 SNS 발행 자산 구분**: 일기장처럼 나만 볼 글과 SNS로 가공할 글을 명확히 분리
   - **👁️ 시크릿 블러 모드 (`⌘B`) & 금고 PIN 잠금 (`⌘L`)**: 카페나 주변에 사람이 있을 때 현재 문장 외의 목록을 블러 처리하거나 비밀번호로 잠금

4. **X (Twitter) & Threads 원클릭 발행 스튜디오 ("1 Idea Into 1000")**
   - **🧵 본문 → 스레드 자동 분할**: 아침에 길게 쓴 글을 Threads(500자) 또는 X(280자) 규격에 맞춰 스레드 카드로 자동 분할 및 번호(`1/N`) 부여
   - **✨ 드래그한 문장만 SNS 카드로 발췌**: 지극히 개인적인 아침 일기 중에서도 마음에 드는 통찰 한 문장만 드래그하여 SNS 카드로 추출
   - **🔥 Dan Koe 첫 문장(Hook) 공식 칩**: 클릭 한 번으로 카드 상단에 검증된 훅 구조 삽입
   - **원클릭 웹 발행 연동**: `Threads 발행 ↗`, `X 발행 ↗` 클릭 시 텍스트가 자동으로 채워진 발행 창 실행 + 감성 타이포그래피 카드 이미지(PNG) 생성 및 복사
